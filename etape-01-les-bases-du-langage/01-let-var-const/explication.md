# 1.1 - Let, var, const

En TypeScript, il y a 3 mots pour créer une variable :

1. **`const`** : Pour une valeur qui **ne change jamais** (ex: une date de naissance, un prénom).
2. **`let`** : Pour une valeur qui **peut changer** (ex: l'âge, un compteur).
3. **`var`** : L'ancienne façon de faire en JavaScript. Il ne respecte pas les blocs `{ }` (comme `if`) et **ne doit plus être utilisé**.
